A bug found by running the app. Filed by whoever found it, labelled
`user-test-bug`, then groomed by the PM like any other issue.

## Goal

One sentence on what should be true when the bug is fixed.

## Description

What was done, step by step, what happened, and what was expected.
Include the screen size, the page URL and the logged-in user when they
matter.
